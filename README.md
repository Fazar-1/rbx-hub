# RBX Hub

Десктопное приложение для Windows — каталог популярных игр Roblox. Поиск, фильтры по жанрам, топы, случайная игра и живые данные по онлайну и рейтингу.

## Что это

Небольшое настольное приложение, которое собирает игры Roblox в один каталог. Не является официальным клиентом Roblox Corporation — это самостоятельный обозреватель каталога.

**Ключевые возможности:**

- **12 048 игр** в локальной базе — приложение работает без интернета, открывается мгновенно
- **Поиск** по названию и жанру с мгновенным результатом
- **Фильтры по жанрам** — Симулятор, Выживание, RP, Обби, Шутер, Стратегия, Магазин, Головоломка и другие
- **Топ сегодня** — 8 самых популярных игр с нумерацией
- **Случайная игра** с настраиваемыми правилами
- **Живые данные** — онлайн, рейтинг и посещения подтягиваются из Roblox и обновляются автоматически
- **Настройки**, которые сохраняются между запусками

## Установка

### Готовый установщик

1. Скачайте `RBX-Hub-Setup-1.3.0.exe`
2. Запустите — установщик предложит выбрать папку
3. На рабочем столе и в «Пуске» появится ярлык **RBX Hub**

Установщик не подписан цифровым сертификатом, поэтому Windows SmartScreen может предупредить о «неизвестном издателе» — нажмите **«Подробнее» → «Всё равно запустить»**.

### Портативная версия

Распакуйте папку `installer/win-unpacked` целиком и запустите `RBX Hub.exe`. Папку нельзя разрывать: `.exe` и соседние `.dll` работают только вместе.

### Удаление

«Параметры» → «Приложения» → «Установленные приложения» → **RBX Hub** → «Удалить». Настройки удаляются вместе с приложением.

## Использование

### Основное

| Действие | Как |
|---|---|
| Поиск игры | Введите название или жанр в поле поиска |
| Фильтр по жанру | Чипы под заголовком каталога |

## Настройки

Кнопка **⚙ Настройки** в правом верхнем углу. Сохраняются на этом компьютере автоматически.

### Внешний вид
- **Плотный список** — карточки мельче, на экран влезает больше игр
- **Показывать статистику** — плитки «игр в базе», «жанров», «средний рейтинг», «играют сейчас»
- **Иконки игр** — можно выключить, если картинки не загружаются
- **Карточек на странице** — 24 / 48 / 96 / 144

### Случайная игра
- **Только из текущего фильтра** — выбирать среди отобранных поиском и жанром
- **Не повторять недавние** — последние 5 / 20 / 50 игр не выпадают
- **Минимальный онлайн** — любой / 100 / 1 000 / 10 000 / 50 000
- **Минимальный рейтинг** — ползунок от 0 до 5
- **Жанр** — ограничение выборки одним жанром
- **Попробовать** — сразу проверить результат

### Данные
- **Обновлять онлайн и рейтинг** — включение и выключение запросов к Roblox (время загрузки всех 310 игр — около 1 секунды)
- **Частота обновления** — 30 секунд / минута / 5 минут / 15 минут
- **Обновить сейчас** — ручное обновление с отметкой времени

### Окно и масштаб
- **Масштаб интерфейса** — кнопками или горячими клавишами, от 60% до 250%
- **Открывать игры** — в окне приложения или сразу в браузере
- **Сортировка каталога по умолчанию** — по онлайну / рейтингу / названию
- **Сброс настроек**

## Технологии

| Компонент | Версия |
|---|---|
| Electron | 45.2.3 |
| Electron Builder | 26.18.0 |
| @electron/packager | 20.3.0 |
| Node.js | 24+ |

Стек намеренно минималистичен: интерфейс — один самодостаточный HTML-файл с нативным JavaScript и CSS, без фреймворков и сборщиков. Это даёт быстрый старт и простую поддержку.

**БезопасностьElectron:**
- `contextIsolation: true`
- `nodeIntegration: false`
- `sandbox: true`
- переходы по незнакомым адресам блокируются
- внешние ссылки открываются только в браузере, и только на домены `roblox.com`

## Сборка из исходников

### Требования
- Node.js 24 или новее
- Windows x64

### Шаги

```bash
# 1. Зависимости
npm install

# 2. Сборка интерфейса: подставить базу игр в шаблон
node -e "const fs=require('fs');let t=fs.readFileSync('index_src.html','utf8');const db=fs.readFileSync('games-full.json','utf8');const arr=db.slice(db.indexOf('['),db.lastIndexOf(']')+1);t=t.replace('__GAMES__',arr);fs.writeFileSync('ui/index.html',t,'utf8')"

# 3. Запуск в режиме разработки
npm start

# 4. Сборка установщика
npm run dist
```

Результат — в папке `installer/`.

> При первом запуске Electron может долго скачивать бинарник. Если возникает ошибка сети, скачайте архив `electron-v45.2.3-win32-x64.zip` вручную и распакуйте в `node_modules/electron/dist/`.

## Обновление базы игр

Скрипт `fetch-games.cjs` собирает игры из публичных данных Roblox: топы, подборки и поиск по 93 жанровым запросам, убирает дубликаты и уточняет жанры по названиям.

```bash
node fetch-games.cjs
```

Скрипт запишет `games-full.json`. После этого повторите сборку интерфейса (шаг 2 выше) и пересоберите установщик.

**Структура записи:**

```json
{
  "n": "Steal An Egg",          // название
  "g": "Симулятор",             // жанр
  "p": 562860,                  // онлайн на момент сбора
  "r": 4.6,                     // рейтинг 0–5
  "u": 10563114921,             // universeId
  "pl": 107778070777162         // placeId
}
```

## Источники данных

Приложение обращается к публичным веб-эндпоинтам Roblox:

| Что | Адрес |
|---|---|
| Онлайн, посещения, голоса | `https://games.roblox.com/v1/games?universeIds=…` |
| Рейтинг (голоса за/против) | `https://games.roblox.com/v1/games/votes?universeIds=…` |
| Каталог и подборки | `https://apis.roblox.com/explore-api/v1/get-sorts` |
| Поиск игр | `https://apis.roblox.com/search-api/omni-search` |

Статичный снимок каталога хранится в `games-full.json`, поэтому базовая работа не зависит от доступности API. Если Roblox недоступен, приложение показывает последние известные цифры и индикатор «нет связи с Roblox».

## Ограничения

- Приложение не связано с Roblox Corporation и не заменяет официальный клиент
- API Roblox публичные, но не имеют официального контракта — при изменениях на стороне Roblox обновление данных может перестать работать
- Установщик не подписан сертификатом: возможен запрос SmartScreen, а anti-virus может ложно срабатывать на неподписанные Electron-сборки
- Иконки игр загружаются с CDN Roblox (`tr.rbxcdn.com`) — при недоступности домена остаются буквенные заглушки
- Размер портативной сборки около 400 МБ — стандартный вес Electron
